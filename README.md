# ST-GCN + FiLM for fMRI-based ASD classification

A spatial–temporal graph-convolutional model (ST-GCN) with FiLM conditioning that classifies windows of parcelwise BOLD signals as autistic vs non-autistic. The model builds functional-connectivity graphs from Brainnetome (274) parcel time-series, and can optionally incorporate subject-level demographic features (age, gender, FSIQ).
