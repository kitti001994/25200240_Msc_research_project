# ST-GCN + FiLM for fMRI-based ASD classification

This project tested whether laughter-based task-fMRI carries an autism-related signal detectable by a spatio-temporal graph convolutional network (ST-GCN), and whether using Feature-wise Linear Modulation (FiLM) for condition detection improves classification. Using Cai’s (2024) dataset of 23 autistic and 23 non-autistic adults, the Brainnetome atlas was used to define brain regions as graph nodes and 20-TR windows as edges. Features were then analysed using K-fold (5-fold) and leave-one-subject-out (LOSO) cross-validation. The plain ST-GCN reached a window-level test AUC of 65.7%, because this was computed over 2365 windows drawn form only six held-out participants. It measured within-scan separability rather than the ability to classify a new person. Under LOSO validation the same model reached an AUC of 56.3%. FiLM did not improve the network, and per-condition analysis showed that no specific laughter type carried a distinctive signal. Restricting the graph to the top ten most discriminative regions reduced subject-level AUC to 44.4%, and including FiLM reduced it further to 36.3%, suggesting that the signal is spatially distributed and the usable signal was excluded. Furthermore, an 82.2% AUC achieved by adding demographic features (age, sex, and FSIQ), however the five-seed stability test showed that it was a single-seed artefact, with true performance remaining only near 57.7% (SD 3.3%). The study concludes that due to the small dataset size, this complex model was not able to find generalisable signal distinguishing autistic from non-autistic participants.
